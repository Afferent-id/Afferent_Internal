## ⚡ About Me

> *"I'd rather ship a working detection pipeline than just read about one."*

I am a **Telecommunication Engineering Student** specializing in **network defense, security operations (SecOps), and cloud infrastructure**. My work bridges the gap between **AI-driven threat detection, human-centric security telemetry, and scalable cloud pipelines**.

```text
 ┌────────────────────────────────────────────────────────────────────────────┐
 │  🛡️ SOC Pipelines    : AI-assisted IDS/SIEM/SOAR threat monitoring         │
 │  🌐 Network Defense  : SDN/NDN intrusion prevention & OpenFlow automation  │
 │  🧠 Human Telemetry  : Phishing simulation & crowdsourced threat triaging   │
 └────────────────────────────────────────────────────────────────────────────┘
```

- 🛡️ **Building [Human Firewall Platform](#-featured-projects)** — A closed-loop phishing simulation & crowdsourced threat reporting platform powered by GoPhish, Flask, n8n, VirusTotal, & Next.js.
- 🤖 **Deployed AI-Assisted SOC Engine** — Transformer-based intrusion detection model (**92.69% recall, 97.42% ROC-AUC**) validated on live SSH brute-force traffic.
- 🔬 **Researching Next-Gen Networks** — SDN-based IPS and Cache Pollution Attack mitigation for Named Data Networking (IEEE submission track).
- 📊 **Building Telecom KPI Analytics** — ETL pipelines & exploratory ML (clustering, anomaly detection, forecasting) for 90+ real operational KPIs.
- 📈 **Leadership** — Lead Human Capital for a research lab, designing quantitative KPI evaluation frameworks.
- 🌱 **Currently Deepening** — AWS Cloud Security Architecture & Microsoft SC-500.
