## 2. MODEL RISIKO FINANSIAL & CYBER ROI (ALE / SLE MODEL)

Platform mengimplementasikan model formulasi risiko **Annualized Loss Expectancy (ALE)** untuk memberikan jawaban konkret atas *Return on Investment (ROI)* keamanan siber kepada CFO dan CISO.

### 📐 Formulasi Risiko Finansial:
1. **Single Loss Expectancy (SLE) [P]:**  
   $$\text{SLE} = \text{Asset Value} \times \text{Exposure Factor (EF)}$$  
   *(Asumsi rata-rata biaya kerugian 1 insiden phishing/kebocoran kredensial karyawan = Rp 15.000.000,-)*

2. **Annualized Rate of Occurrence (ARO) [P]:**  
   $$\text{ARO} = \text{Jumlah Klik Phishing Bulanan} \times 12$$

3. **Annualized Loss Expectancy (ALE) [P]:**  
   $$\text{ALE} = \text{SLE} \times \text{ARO}$$

### 📊 Model Proyeksi Penghematan Biaya (Cost Savings Projections) [P]:
$$\text{Cost Savings (IDR)} = \text{ALE}_{\text{Sebelum Human Firewall}} - \text{ALE}_{\text{Terkini}}$$

```text
 ┌────────────────────────────────────────────────────────────────────────────┐
 │  Studi Kasus Proyeksi Perusahaan (1.000 Karyawan):                          │
 │  • ALE Sebelum Pelatihan  : Rp 450.000.000,- / tahun (30 klik insiden/thn) │
 │  • ALE Terkini (Proyeksi) : Rp  60.000.000,- / tahun (4 klik insiden/thn)  │
 │  • Total Penghematan Risiko Finansial (ROI) : Rp 390.000.000,- / tahun!    │
 └────────────────────────────────────────────────────────────────────────────┘
```

## 4. STRATEGI GO-TO-MARKET (GTM) & SKEMA MONETISASI

### 💼 Model Pendapatan (B2B SaaS Pricing) [P]
* **Skema Per-User Per-Month (PUPM):**
  * **Standard Tier:** $1.50 / user / bulan (Rp 22.500,-) — Termasuk Simulasi Phishing GoPhish, Telegram Bot, & Basic Analytics.
  * **Enterprise All-in-One Tier:** $2.50 / user / bulan (Rp 37.500,-) — Termasuk MS Teams/Slack Bot, Dynamic Badges, Custom Intel, & SIEM Export.
* **Proyeksi Pendapatan Tahunan (ARR) [P]:**
  * 50 Klien Enterprise $\times$ 1.000 User $\times$ $2 / bulan = **$1.200.000 / tahun (~Rp 18 Miliar ARR)**.

### 🚀 Strategi Go-To-Market (GTM Phased Launch) [P]
1. **Fase 1 (Design Partner / Beta Pilot):** Uji coba gratis 1 bulan dengan 3-5 perusahaan mitra (Fintech/BPR lokal) untuk mendapatkan data kepuasan & testimoni (*Social Proof*).
2. **Fase 2 (Direct B2B Enterprise Sales):** Penjualan langsung ke CISO/IT Director di sektor Keuangan & Telekomunikasi.
3. **Fase 3 (Channel Partner & MSSP):** Bermitra dengan penyedia *Managed Security Service Provider (MSSP)* lokal sebagai paket tambahan perlindungan pengguna.
