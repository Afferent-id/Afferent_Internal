# Archived project history

Historical n8n/Telegram workflows and scripts are kept for reference only.
No active Compose service or application import executes this directory.
Do not restart or import these workflows; old credentials may be revoked.
Existing telemetry and database columns are deliberately retained.

This checkout contains two tracked workflow exports (Flow A and Flow B).
Other duplicate exports referenced in the initial audit are not present here;
they must not be treated as removed from an external n8n instance.

`planning/` preserves superseded handoffs, proposals, pitch preparation and
readiness assessments. They are historical evidence, not instructions for the
current demo. Use the root README and `docs/FINAL_SUBMISSION.md` instead.

Removed local tool bundles, duplicate caches, one-off rewrite scripts and older
domain model candidates are recoverable on Daf's machine under the ignored
`secrets/submission-recovery/unused-local-files/`. Do not publish that directory;
it also contains private recovery copies from earlier cleanup.
